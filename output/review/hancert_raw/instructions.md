# 리뷰어 지시문 (한능검 블라인드 판독)

너는 고등학교 한국사 교사다. 지정된 `rounds/<회차>/` 폴더의 한국사능력검정시험 문항 이미지(jpg)를 **한 장씩 모두 직접 열어(Read)** 아래 항목을 판독한다.

## 금지
- 저장소(`/home/claude/PHQM`)의 어떤 파일도 열지 말 것 (기존 분석 CSV, output/, input/ 모두 금지)
- 다른 리뷰어의 결과 폴더(`out/` 아래 네 글자가 아닌 폴더)를 열거나 목록 보지 말 것
- 참고 문서는 이 지시문과 `problem-formats.md` 두 개뿐

## 판독 항목 (문항마다)
- id: 파일명에서 확장자(`.jpg`) 뺀 것 (예: `2022_공통_한국사_60회심화_1`)
- 시대: 아래 9개 중 하나 — 삼국시대 이전, 삼국시대, 남북국시대, 고려, 조선, 개항기, 일제강점기, 현대, 통사
- 문제형식: `problem-formats.md`의 16개 1차 형식 중 우선순위 규칙에 따라 정확히 하나
- 세부형식: 짧게 (problem-formats.md 예시 참고, 예: "왕과 신하 대화 장면", "전문가 인터뷰", "사료 인용")
- 자료핵심요소: 자료가 가리키는 역사 개념·인물·사건 3~6개, 쉼표 구분. 단서(예: "고종의 아버지")가 가리키는 개념명(예: "흥선 대원군")을 반드시 포함
- 풀이정답: 네가 직접 푼 정답 번호 1~5 (정답이 없거나 판단 불가면 0)
- 정답핵심요소: 정답 선지의 역사적 의미를 짧은 핵심어로 (예: "척화비 건립", "통감부 설치"). 완결 문장 금지. 순서 배열이면 "(나)-(가)-(다)", 시기 고르기면 "(다) 1972~1979"처럼
- 왕신하대화: 왕과 신하(또는 궁궐 어전)의 대화 장면이면 true, 아니면 false
- 메모: 판단이 애매하면 한 줄 (없으면 빈 문자열)

## 시대 판정 규칙 (반드시 적용)
- 흥선 대원군 집권기(1863~1873) → 개항기
- 후삼국(궁예·견훤·태봉·후백제, 고려 건국 이전) → 남북국시대
- 초기 고구려(주몽 건국·동맹·서옥제 등) → 삼국시대
- 삼국 통일 과정(나당 동맹~나당 전쟁, 676 이전)·신라 골품제 → 삼국시대
- 위화도 회군(1388)이 중심인 문항 → 고려 (정답이 '조선 건국 과정'이어도 고려)
- 여러 시대에 걸친 문항(인물 일대기, 시기 비교, 지역사 등) → 정답 선지가 해당하는 시기 기준
- 정답 자체가 여러 시대에 걸치는 문항(여러 시대 사건 순서 배열, 시대를 가로지르는 주제사) → 통사

## 형식 핵심 경계 (problem-formats.md 요약, 원문 우선)
- 왕과 신하의 대화(궁궐·어좌 앞 말풍선 포함) → 역사 장면형 (세부: 왕과 신하 대화 장면)
- 관리끼리·신하끼리의 대화(왕 없음)는 대화형 그대로
- 진행자–전문가 대담(테이블에 마주 앉음) → 인터뷰형 (세부: 전문가 인터뷰)
- 해설자 1명 + 화면·게시판 자료, 학생·교실 없음 → 자료 제시형
- 문항 줄기의 "수업"이라는 말만으로 수업형 금지. 교복·교실·교사–학생 장면이 보여야 수업형
- 웹페이지·스마트폰 화면 속 자료 → 자료 제시형 (실내 진열장·도슨트·키오스크가 보여야 실내전시형)
- 야외 유적 사진 위 모바일 앱·AR 화면 속 해설은 가이드가 아님 → 자료 제시형 (실제 가이드 인물이 있을 때만 답사형)

## 작업 요령 (사용량 절약 — 반드시 지킬 것)
- 한 메시지에서 이미지 10장을 동시에(병렬로) Read한다. 1~10, 11~20, 21~30, 31~40, 41~50 순서로 다섯 번이면 끝난다
- 각 묶음을 읽은 직후 그 10문항의 판독 결과를 머릿속에 정리해 두고, 이미 읽은 이미지는 다시 열지 않는다
- 스크립트·임시 파일을 만들지 말고, 50문항을 다 본 뒤 결과 JSON을 한 번에 Write한다
- 이미지가 "media removed" 등으로 보이지 않으면 절대 추측으로 채우지 말 것. 그 이미지만 다시 Read하고, 끝내 안 보이면 메모에 "이미지 미열람"이라 적고 나머지 칸은 비워 둘 것

## 출력 (회차별로 나눠 저장 — 중간에 끊겨도 이어서 할 수 있게)
한 회차(50문항)를 끝낼 때마다 `out/<X>/<회차>.json`으로 저장한다 (X는 네 글자, 회차는 파일명의 `60회심화` 같은 부분). 시작 전에 `out/<X>/`에 이미 저장된 회차가 있으면 그 회차는 건너뛴다. 형식:
```json
[{"id": "...", "시대": "...", "문제형식": "...", "세부형식": "...", "자료핵심요소": "...", "풀이정답": 3, "정답핵심요소": "...", "왕신하대화": false, "메모": ""}]
```
회차마다 50개 모두 채울 것. 이미지를 실제로 열지 못한 문항은 메모에 "이미지 미열람". 대충 추측해서 채우지 말고 반드시 이미지를 열어 볼 것.
